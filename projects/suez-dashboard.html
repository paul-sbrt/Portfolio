Client case study

SUEZ Certification Dashboard

Dashboard created at Avanade for SUEZ to monitor Power Platform certifications across teams. This page highlights the key views used to track progress, spot gaps and prepare leadership reviews.

Internal project developed at Avanade — live access no longer available

Project context

The report blends Power BI, Power Query and DAX measures to expose KPIs in a modern Microsoft look-and-feel. It consolidates pipelines and training data so managers can act before deadlines.

Key outcomes

  • Centralized certification progress tracking for multiple teams
  • Improved visibility for managers with clear KPIs and drill-down views
  • Reduced manual reporting by consolidating data into a single dashboard
