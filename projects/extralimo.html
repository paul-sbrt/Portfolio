EXTRALIMO mise en relation HCR

L'hôtellerie-restauration peine à trouver les bons extras ; les candidats manquent de visibilité. EXTRALIMO les relie — mais ce n'est pas un job board en libre-service : la valeur, c'est l'intermédiation humaine, une petite équipe d'admins qui sélectionne, propose et accompagne.

En ligne sur extralimo.portfolio-sbrt.com (52 commits, mise à jour juin 2026). Projet mené avec ses associés.

Visiter le site

La solution

Plateforme web articulée autour de 3 rôles (candidat / entreprise / admin) et d'un objet central, le « match » (suggéré → en cours → contact débloqué → placé). Confidentialité by design : les coordonnées restent masquées tant qu'un admin n'a pas débloqué le contact. Inscriptions publiques mobile-first, consentement RGPD.

Points clés

  • Trois rôles (candidat / entreprise / admin) autour d'un objet « match »
  • Confidentialité by design : coordonnées masquées jusqu'au déblocage par un admin
  • Matchs créés manuellement, placement selon le type de contrat et l'affinité de poste
  • Inscriptions publiques mobile-first, consentement RGPD
  • Modèle économique : commission au contrat (pourcentage sur le placement)

Voir la plateforme

Le produit est en ligne — je peux présenter le modèle de données, le cycle de vie d'un « match » et l'approche confidentialité.
